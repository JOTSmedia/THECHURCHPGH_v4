THE CHURCH — V4 WEBSITE PACKAGE

1. Open a terminal in this website folder and run:
   npm run dev
2. Open the local address printed by the preview server.
3. Open README.md for editing, checking, building, and deployment instructions.

You can also double-click index.html for a basic offline preview. The local server is recommended for full browser behavior and media.

V4 uses local relative pages and assets. No fixed publishing host is embedded. The opening uses an actual studio stained-glass photograph until the replacement image is supplied. The Equipment List expands by category.

The contact form prepares a message for the visitor to review and send. It does not silently submit it.

The console model is preserved independently in Desktop/API. It is not part of this V4 website. Earlier website versions remain separate.

Source audit, photography provenance, and verification notes are in docs/. The original archive referenced in the prior conversation was unavailable and was not merged.
